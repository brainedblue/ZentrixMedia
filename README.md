# ZentrixMedia Website

A freelance website I built for ZentrixMedia, a video editing agency.

Live site: https://zentrixmedia.in

## About

ZentrixMedia needed a website that looked premium, modern, and more visual than a normal agency landing page.

The main idea was to make the site feel close to the work they do — video, motion, visuals, and creative editing. So instead of keeping it flat and basic, I built it with a dark cinematic style, purple highlights, interactive sections, custom video showcases, and a 3D animated background.

## What I Built

I built the complete website as the sole developer.

The site includes a 3D WebGL background, animated sections, custom video cards, service sections, contact options, and a project inquiry form.

Some parts I focused on:

- A 3D animated background using Three.js and WebGL
- Purple neon-style visual theme
- Floating 3D shapes and particles
- A tiled 3D floor/grid effect in the background
- Custom short-form video showcase cards
- Custom long-form video showcase sections
- Play/pause and mute controls for videos
- SVG icons and visual elements
- Animated process section for the client workflow
- Scroll-based animations and reveal effects
- Animated stats section
- Contact options through WhatsApp and Discord
- Project inquiry form using FormSubmit
- Responsive layout for desktop and mobile
- Deployment on Vercel

## Main Sections

### Hero Section

The homepage starts with a clean Zentrix hero section, dark background, bold typography, and call-to-action buttons.

The goal was to make the first screen feel simple but premium.

### Work Showcase

The work section shows different types of video editing work, including short-form content and long-form content.

I created custom video sections instead of using normal embedded players, so the work presentation feels more native to the site.

### 3D Background

One of the main visual parts of the website is the animated 3D background.

It uses a WebGL scene with a purple tiled floor, floating shapes, particles, and depth-based visuals. This gives the site a more futuristic and interactive feel.

### Process Section

The process section explains how ZentrixMedia works with clients, from understanding the brief to final delivery.

I designed it with large numbered cards and glowing connecting lines so it feels more visual instead of just being plain text.

### Contact and Inquiry

The site has quick contact options for WhatsApp and Discord, plus a project inquiry form where users can select video format, editing services, frequency, budget, and reference links.
